# گزارش مرحلهٔ اول — پایهٔ ثابت آزمایش

Map: `/Game/DartLab/Maps/L_DartLab`.

یک کف، نور، نقطهٔ شروع بازیکن، تختهٔ ثابت و دارت مرکب ثابت روی میز ایجاد شدند. GameMode قالب XR حفظ شد. Map و Blueprintهای قبلی، تنظیمات شروع پروژه و دو مورد ذخیره‌نشدهٔ ادیتور باز تغییر نکردند.

سطح تخته 237cm از مبدأ پرتاب x=0 فاصله دارد؛ مرکز آن در ارتفاع 173cm است و قطر آن 45.1cm است. مرکز هندسه در x=239 قرار دارد تا ضخامت 4cm فاصلهٔ سطح جلویی را اشتباه نکند.

دارت این مرحله فقط placeholder است: گرفتن، پرتاب، آیرودینامیک و برخورد نوک هنوز ساخته نشده‌اند. منوهای موجود متعلق به قالب قبلی هستند و در این مرحله ساخته نشده‌اند.

## شواهد

- آزمون پیش از ساخت: شکست مورد انتظار به دلیل نبود Map.
- ساخت Map: Commandlet، exit 0، DART_LAB_CREATE PASS.
- بازخوانی مستقل: Commandlet جدید، exit 0، DART_LAB_VERIFY PASS. ابعاد تخته، کف، اجزای دارت، اتصال فرزندان، برخورد، WorldToMeters و GameMode بررسی شدند.
- در نخستین بازخوانی، پروفایل برخورد دارت BlockAll بود؛ با ثبت NoCollision اصلاح و در اجرای جدید تأیید شد.

## وضعیت جداگانه

| مورد | نتیجه |
|---|---|
| اعتبارسنجی دارایی ذخیره‌شده روی دسکتاپ | موفق؛ با NullRHI، بدون ارزیابی بصری یا گیم‌پلی |
| Compile C++ | اجرا نشده؛ هنوز کد native مرحلهٔ بعد اضافه نشده |
| Compile Blueprint | اجرا نشده؛ Blueprint جدید یا تغییریافته نداریم |
| آمادگی SDK | Win64 معتبر؛ Android INVALID r27c |
| Build و بسته‌بندی Android | اجرا نشده؛ SDK36/NDK27c ناقص‌اند |
| دانلود وابستگی‌ها | ناموفق؛ Google manifest با FileNotFoundException/404 دریافت نشد |
| نصب، Tracking، عملکرد و حس هدست | اجرا نشده؛ دستگاه در دسترس نیست |
| تکمیل پذیرش کل مرحلهٔ اول | هنوز کامل نیست |

## بررسی بعدی کاربر

اکنون می‌توانید Map جدید را پس از رسیدگی به کار ذخیره‌نشدهٔ خود باز کنید. با فراهم‌شدن دستگاه و Build، مقیاس فضا، ارتفاع کف و تخته، شناخت هر دو کنترلر و روانی اجرا را بررسی می‌کنیم. آزمون گرفتن و پرتاب متعلق به مراحل بعد است.

مرحلهٔ بعدی مستقل از هدست: هستهٔ C++، تخمین رهاسازی و تست‌های ریاضی دسکتاپ طبق طرح؛ آماده‌سازی خروجی Android همچنان باز می‌ماند.
